# 📊 Sales Performance Analysis Dashboard | Power BI

## 📌 Project Overview

The **Sales Performance Analysis Dashboard** is an interactive business intelligence project developed using Microsoft Power BI. It provides insights into sales performance, profitability, regional sales distribution, and product-level performance.

The dashboard transforms raw sales data into meaningful visual insights, helping stakeholders monitor key performance indicators (KPIs) and make data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track monthly sales trends.
- Compare sales across product categories and regions.
- Identify the top 10 products by sales.
- Evaluate profit contribution by product category.
- Enable interactive analysis using slicers.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX (Data Analysis Expressions)** — KPI measures and calculations

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard includes the following metrics:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin (%)

### 2. Sales Trend Analysis

A line chart visualizes monthly sales trends to help identify changes in sales performance over time.

### 3. Sales by Category

Analyzes sales distribution across product categories to compare category-level performance.

### 4. Sales by Region

Compares sales across geographical regions to identify stronger and weaker sales areas.

### 5. Top 10 Products by Sales

Highlights the ten highest-performing products based on sales value.

### 6. Profit by Category

Evaluates profit contribution across product categories to support profitability analysis.

### 7. Interactive Slicers

The dashboard includes interactive filters for:

- Date
- Region
- Category

These slicers allow users to explore the data dynamically and analyze specific segments of the business.

## 🧹 Data Preparation

Power Query was used to prepare the raw dataset for analysis.

Key data preparation activities included:

- Standardizing inconsistent text values.
- Removing unnecessary whitespace and cleaning text fields.
- Addressing duplicate records and irrelevant columns.
- Preparing date and categorical fields for visualization.

## 📊 Key Business Questions

This dashboard helps answer questions such as:

- What are the overall sales and profit figures?
- How do sales change month by month?
- Which product categories generate the highest sales?
- Which regions contribute the most to sales?
- Which ten products have the highest sales?
- How does profitability vary across categories?
